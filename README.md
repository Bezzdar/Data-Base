# 🏢 Реализация базы данных для агентства недвижимости

Этот проект содержит реляционную базу данных, разработанную в рамках лабораторной работы по дисциплине "Базы данных". Цель — моделирование и реализация структуры агентства недвижимости с соблюдением требований нормализации, ссылочной целостности и типизации.

---

## 🛠 Стек технологий

- СУБД: **MySQL 8.x**
- Клиент: **MySQL Workbench**
- Формат экспорта: `.sql`

---

## 📁 Структура проекта
sql_exports/ └── real_estate_agency.sql — SQL-дамп со структурой и/или данными
