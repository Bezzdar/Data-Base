# 🏢 Реализация базы данных для агентства недвижимости

Этот проект содержит реляционную базу данных, разработанную в рамках лабораторной работы по дисциплине "Базы данных". Цель — моделирование и реализация структуры агентства недвижимости с соблюдением требований нормализации, ссылочной целостности и типизации.

## 🧱 Состав базы данных

База данных включает следующие таблицы:

1. `Client` — информация о клиентах (ФИО, пол, доход, профиль)
2. `ClientContact` — нормализованные контакты клиентов (телефон, почта, Telegram)
3. `Realtor` — сотрудники риелторского агентства
4. `Property` — объекты недвижимости
5. `Deal` — сделки (аренда или покупка)
6. `Contract` — заключённые договоры

---

## 🎯 Особенности реализации

- **Нормализация:** все таблицы соответствуют требованиям **3НФ**
- **Ограничения:**
  - `CHECK` на числовые поля (`доход`, `площадь`, `цена`)
  - `DEFAULT` значения для дат и логических флагов
  - `ENUM` для выбора типа объекта, пола, способа оплаты и пр.
- **Типы данных:**
  - `TEXT`, `LONGTEXT` — длинные строки и описания
  - `BOOLEAN` — флаги активности и статуса
  - `LONGBLOB` — для хранения изображений
- **Ссылочная целостность:** `FOREIGN KEY` и `ON DELETE CASCADE` применены
